# Matrix Rain · 把 Mac 屏保变成代码雨

一个黑底绿字的代码雨网页，一段 **2560 × 1440、30 帧/秒、30 秒循环**的视频，以及一份从下载到设置屏保的中文教程。

**只想使用？[打开下载页 →](https://github.com/cyberxz2077/matrix-rain-screensaver/releases/latest)**，下载 `.mov` 视频，再看下面的安装步骤。无需运行代码。

想用 AI 改颜色、速度或分辨率？复制 [PROMPTS.md](PROMPTS.md) 里的提示词，并附上 [matrix-rain.html](matrix-rain.html)。

## 1. 拿到视频

在仓库右侧找到 **Releases**，点最新版本，展开 **Assets**，下载 `matrix-rain-2560x1440-30s-hevc.mov`。这是 HEVC 编码的 MOV 版本。`.mp4` 是 H.264 通用预览版，`Source code` 是源码压缩包。

下载后先用 QuickTime 播放，确认是你想要的代码雨。MOV 是视频容器；把 `.mp4` 的后缀直接改成 `.mov`，不等于完成转换。

## 2. 找一个不用的原生屏保

这里介绍一个“骚操作”：借用一款原生屏保的入口，把它的视频换成自己的。

以下路径对应 **macOS 26（Tahoe）**。本机检查基于 macOS 26.6.2；旧版系统的路径可能不同。

1. 打开 **系统设置 → 墙纸 → 屏幕保护程序**，选择 **自定义**。
2. 找一个平时不用的原生动态屏保，例如 **太浩湖清晨**。有下载箭头就先下载，等下载完成后选中它。
3. 记住这个名称；替换后在系统设置中仍然使用这个名称。

## 3. 找到文件，先备份

打开 **访达（Finder）**，按 **⌘ Command + ⇧ Shift + G**，粘贴下面这行路径并回车：

```text
~/Library/Application Support/com.apple.wallpaper/aerials/videos/
```

里面通常是一些名称很长的 `.mov` 文件。**选中文件，按空格快速预览**，找到刚刚选的原生屏保。不要只凭文件大小或排序猜。

1. 在桌面新建“原生屏保备份”文件夹。
2. 将目标原视频**复制**进去，保留它的原始名称。备份文件夹放在上述 `videos` 目录之外。
3. 打开目标文件的“显示简介”（⌘I），展开“名称与扩展名”，复制**完整文件名，包括 `.mov`**。

如果文件夹不存在或找不到对应视频，先确认系统版本与下载状态，暂时不要替换别的文件。

## 4. 同名替换

1. 回到“下载”文件夹，打开代码雨 MOV 的“显示简介”（⌘I），在“名称与扩展名”中按 ⌘A 全选，再粘贴刚复制的完整名称。确认结尾只有一个 `.mov`，避免变成 `.mov.mov`。
2. 将它拖入原生 `videos` 文件夹，出现同名文件提示时选择 **替换**。
3. 回到系统设置，重新选择刚才那款屏保；必要时先选另一款再切回来。
4. 名字和缩略图可能仍是“太浩湖清晨”，实际播放内容会来自被替换的视频。
5. 点击预览，至少看完两轮；再实际进入屏保，检查播放、循环与唤醒后的表现。

**想还原：**把备份中的原文件复制回相同位置，覆盖同名文件，然后重新选择原屏保。

## 常见问题

**这是苹果官方支持的导入方式吗？** 不是。这是替换本地已下载视频的做法；系统更新或重新下载原视频可能覆盖替换结果。这里不需要关闭 SIP、改安全设置或修改系统目录权限。

**视频内容能循环，系统就一定无缝吗？** 不一定。本项目验证了视频内容的 30 秒周期和每帧时序；不同播放器是否重复播放、循环时是否停顿，是另外一层行为。原生屏保对自定义视频的循环、锁屏和睡眠唤醒表现需要在自己的 Mac 上实际检查。

**黑屏、只播一次或唤醒后卡住怎么办？** 先恢复备份，确认原生视频正常。MOV 内部可以使用不同编码；本项目的原始导出是 H.264，下载页另提供 HEVC MOV。部分 Tahoe 自定义壁纸项目报告 HEVC 更兼容，但不代表所有 Mac 都有同样结果。不要通过反复覆盖未知文件来排查。参考链接见文末。

**多久后进入屏保？** 到系统设置的“锁定屏幕”调整闲置后启动屏保的时间，并检查关闭显示器的时间是否过早。不同系统的小版本界面可能不同。

## 想自己生成视频

只看网页：下载源码后，用浏览器打开 `matrix-rain.html`。

导出视频需要 **Node.js 20+** 和已经安装的 **Google Chrome**。在项目目录执行：

```bash
npm ci
npm run export
```

输出为 `output/matrix-rain-2560x1440-30s.mp4`。也可以指定尺寸与新文件名：

```bash
npm run export -- 1920 1080 output/matrix-rain-1920x1080-30s.mp4
```

在 macOS 上，用下面的脚本无损换成 MOV 容器（需可用的 Swift 命令行工具）：

```bash
swift scripts/to-mov.swift output/matrix-rain-2560x1440-30s.mp4 output/matrix-rain-2560x1440-30s.mov
```

这一步保留 H.264 编码，不会变成 HEVC。脚本拒绝覆盖已有输出文件。

如果已安装 FFmpeg，可以另存 HEVC 版（下面使用 Mac 的硬件编码器）：

```bash
ffmpeg -n -i output/matrix-rain-2560x1440-30s.mp4 -c:v hevc_videotoolbox -b:v 18M -tag:v hvc1 -an -movflags +faststart output/matrix-rain-2560x1440-30s-hevc.mov
```

HEVC 是一次重新编码，和无损换容器不同。预制 HEVC MOV 已完成本机 AVFoundation 全帧解码检查；还需在自己的原生屏保中检查实际循环与唤醒行为。

## 为什么能衔接

普通随机代码雨每次都在变，录 30 秒再重播，结尾很难接上开头。本项目把随机字符、下落位置和拖尾绑定到固定的 **900 帧周期**，再逐帧导出。

- 第 0 帧与第 900 帧表示相同状态；实际导出第 0–899 帧，不多塞一张重复的结尾帧。
- 拖尾从上一周期重建，所以开头不是从黑屏开始。
- 导出不依赖录屏速度，900 帧对应精确 30 秒。

源码检查：`npm run check`。本机已对原始 2560×1440 视频完成 AVFoundation 全帧解码、900 帧计数和时间戳检查。文件验证不替代原生屏保的长期运行验证。
